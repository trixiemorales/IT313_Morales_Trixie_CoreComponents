

# IT 313 Laboratory 6
## Student Directory Viewer

### Problem Description
The Student Directory Viewer is a React Native application
that allows an adviser to browse, search, and flag students
for academic advising.

### Components

StudentCard.js:
Displays student photo, name, year level,
and the Flag for Advising button.

StudentDirectory.js:
Manages the student list, search filtering,
and flag toggle state.

students.js:
Contains the student information and photo URLs.

App.js:
Serves as the main application entry point.

### React Native Components
- View
- Text
- Image
- ScrollView
- TextInput
- Pressable

### How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

   npx expo start

4. Scan the QR code using Expo Go.
